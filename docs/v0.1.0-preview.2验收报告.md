## 1. 本次候选内容

- 设置 schema v10，以及陪伴、专注、安静、休眠四种本地角色模式。
- 模式策略统一接入 Agent、TTS、系统/插件观察、音乐反应和基础动画。
- 调度器的模式、拖动、菜单暂停原因相互独立；收敛模式时取消运行中和排队中的自主动作。
- 首次启动能力/隐私说明、设置页模式影响预览和应用版本标识。
- 仅本地的脱敏诊断导出；诊断由前端运行记录和 Rust 设置摘要双重白名单构成。
- Animation Studio 生产资产加载、动作能力降级和异常拒绝回归。

- [x] 安静模式显示 Agent、朗读和外部反馈暂停，番茄钟保持可用。
- [x] 休眠模式下角色进入闭眼休眠姿态。

- [x] `Ctrl+Shift+Q` 可可靠退出；复测结束后未残留绨络窗口。

用户于 2026-07-29 完成实际试用并确认完整行为矩阵未发现问题：

- [x] 陪伴模式下，已由用户开启的 Agent、TTS 和外部反馈可用，关闭的总开关不会被模式反向开启。
- [x] 专注模式下，对话、Agent 工具与番茄钟可用，音乐律动明显减弱，插件一次性反馈频率降低。
- [x] 安静模式切入时，当前朗读立即停止，Agent 工具暂停，媒体/插件反应收敛；纯文本聊天、手动招手、拖动、菜单和番茄钟仍可用。
- [x] 休眠模式下，跟随、耳动和头发动态停止；拖动、右键菜单、托盘和退出路径仍可操作。
- [x] 在休眠或安静模式打开菜单、拖动后返回，Agent 不会被误恢复；切回陪伴后才按用户总开关恢复。
- [x] 切换模式不会清空窗口位置、番茄钟、记忆、插件、Provider 或 API key 状态。
- [x] `prefers-reduced-motion` 继续高于模式动画策略。
