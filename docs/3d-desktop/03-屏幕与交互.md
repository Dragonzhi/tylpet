# 03 · 屏幕与交互

> **状态**：定稿
> **上游**：[01-产品愿景](01-产品愿景.md)、[02-角色系统](02-角色系统.md)
> **下游**：[04-游戏外壳](04-游戏外壳.md)、[05-表现层](05-表现层.md)

本档定义用户与异世界的唯一接触面：那块半透明悬浮虚拟屏幕，以及围绕它的全部交互规则。

## 1. 屏幕契约

**术语**：本档与全项目统一使用「**悬浮虚拟屏幕**」指代游戏内那块用于表示玩家屏幕的半透明悬浮界面，简称「虚拟屏幕」。锚点类型标识符仍为 `screen_front`。

屏幕是平台级核心对象，不是普通场景装饰：

- 每个世界必须提供一个虚拟屏幕锚点（位置、朝向、尺寸、角色可接近范围由世界包声明）；
- 屏幕在异世界中是半透明的悬浮虚拟屏幕，始终存在；
- 角色知道屏幕后面存在用户；玩家画面就是这个屏幕的另一侧视野；
- 屏幕待机时保持半透明空白或低亮度，不显示任何真实桌面内容。

屏幕表现形态由世界作者决定外观（显示器、镜子、舷窗等），但交互协议统一。

**与休息的衔接**：当角色正在休息时，本节的「点击触碰」与 [04-游戏外壳](04-游戏外壳.md) 的聊天发送构成两个唤醒入口，均走统一 refusal 判定，详见 [02-角色系统](02-角色系统.md) 第 8.1 节。

## 2. 鼠标映射：光点与触点

玩家隔着虚拟屏幕与角色互动，类似**隔着玻璃向另一侧的人指点位置**：玩家只能在屏幕上敲点，不能直接抓取或拖动世界中的物体。

**光点**

- 光点是**玩家唯一指针**：运行时隐藏系统光标，用一枚半透明羽化圆形光点替代；
- 光点绘制在虚拟屏幕表面（3D 世界空间，带透视），玩家与角色都可见；
- 光点与角色感知共用同一个 3D 坐标源，因此角色能真实地看向它；
- 角色可以追踪光点位置，转头或注视对应方向。

**触点**

- 点击屏幕时在光点位置产生触点反馈（波纹扩散 / 敲击感）；
- 触点只是**用户触碰信号**，不等同于直接点击角色，不直接打开角色菜单。

**参数归属**

光点与触点是核心固定的交互表现，**不随世界包变化**；世界包只声明屏幕的位置、朝向、尺寸与可接近范围。建议默认值（Phase 1 可调）：

| 参数 | 建议默认值 |
| --- | --- |
| 光点直径 | 约屏幕高度的 1.5% |
| 光点不透明度 / 颜色 | 0.7 / 冷白 `#CFE6FF` |
| 光点跟随阻尼延迟 | 约 100ms（略滞后于鼠标，强化空间感） |
| 触点波纹半径 / 时长 | 0 → 0.35 世界单位 / 450ms |
| 触点透明度 | 0.8 → 0 |
| 角色追踪角速度上限 | 60°/s |

进入 ESC 浮层或 HUD 交互时恢复系统光标。

## 3. 屏幕点击的语义与优先级

- **屏幕点击只是用户触碰信号**，不等同于直接点击角色，不直接打开角色菜单；
- 优先级为**中等**：可以让角色注意屏幕并提前结束漫步或待机，但不强制打断不可打断活动；
- 角色触碰屏幕的主要含义是**确认用户存在并等待回应**；她只等待几秒到几十秒，没有回应时自然返回自己的活动。

## 4. 角色回应层级

角色主动观察屏幕的触发条件：需求达到阈值、人格倾向允许、屏幕状态适合观察。回应按低打扰到高介入逐级升级：

```mermaid
graph LR
    A["远处看向屏幕"] --> B["走近屏幕"]
    B --> C["触碰 / 敲击屏幕"]
    C --> D["留下极低频 3D 文字"]
```

- **主动文字规则**：极低频且有意义才出现；有冷却和长度限制，默认不连续发送；
- 用户在角色等待期间移动光点或点击回应时，角色播放一个短动作、简短文字或表情，然后尽量恢复被打断的活动。

## 5. 聊天面板

- 形态：**游戏内覆盖面板**（ESC 或按钮呼出），不再使用独立 OS 窗口；
- 打开面板时**世界继续生活**，角色不会因为面板打开就僵住；打字时她可能继续做自己的事，回应时转向屏幕；
- 聊天面板的实现细节（ESC 行为、焦点管理）见 [04-游戏外壳](04-游戏外壳.md)；回复的表现形式（3D 文字、口型、TTS）见 [05-表现层](05-表现层.md)。

## 6. 番茄钟联动

保留现有可靠番茄钟系统，以**游戏内 HUD + 角色 Focus 联动**接入：

- 游戏内可开启 / 查看番茄钟，HUD 显示剩余时间；
- 开启期间角色进入专注陪伴姿态，减少主动打扰；
- 番茄结束角色起身招手并提醒，HUD 显示完成状态。

## 7. 第一个世界的空间边界

首个世界不加入物件系统，只包含：

- 程序化 Blender 无限网格；
- 屏幕前的一块有限活动平台；
- 一个统一的半透明悬浮虚拟屏幕锚点；
- 角色的默认活动区和少量目标点。

角色只允许在默认活动区和虚拟屏幕锚点之间移动。活动平台与虚拟屏幕锚点的空间关系：屏幕位于活动平台前方，角色从活动区走向屏幕是一个独立的、有意图的行为。

## 8. 与桌面图标的关系（远期）

第一阶段角色只把悬浮虚拟屏幕当作连接用户的窗口，不感知、不读取、不操作真实桌面图标。桌面图标作为“窗外世界”接入属于第二阶段透明桌面模式的内容，见 [09-第二阶段预留](09-第二阶段预留.md)。
