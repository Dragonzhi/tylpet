# 04 · 游戏外壳

> **状态**：定稿
> **上游**：[01-产品愿景](01-产品愿景.md)、[03-屏幕与交互](03-屏幕与交互.md)
> **下游**：[08-实施路线](08-实施路线.md)

本档定义全屏游戏的“壳”：窗口形态、启动退出、失焦行为、运行状态机、存档。

## 1. 窗口与显示

- **显示方式**：无边框窗口化全屏（borderless windowed fullscreen）；
- **多显示器**：固定主显示器，第一阶段不做多屏适配；
- **启动**：双击直接进入异世界，不经过主菜单。

## 2. 退出路径

三条路径都保留：

1. ESC 菜单中的“退出”按钮；
2. Alt+F4；
3. 系统托盘右键退出。

## 3. ESC 浮层

- ESC 打开聊天与设置浮层，**不暂停世界**；
- 角色在浮层后面继续生活；聊天面板即浮层中的输入区；
- 设置项包括：画质三档、音频分层（音乐/环境/TTS）、活动节奏偏好（安静/标准/活跃）。

## 4. 失焦行为

- 窗口失焦时**继续以低帧率运行**，世界不冻结；
- 失焦超过 **5 分钟**完全暂停（停止渲染与生活结算）；
- 回到窗口立即恢复，并按离线时长做轻量状态结算：只更新精力、情绪等状态和最后活动结果，**不生成虚构的离线经历**。

### 4.1 离线轻量结算

结算在恢复时一次性完成，**不重放活动序列**，也不产生任何记忆条目。

设离线时长 `T`（小时，**封顶 8 小时**，超出部分按 8 小时计），四个需求按下列公式单向更新一次：

```text
energy    = clamp(energy    + 0.10 × T, 0, 1)                    // 休息恢复
boredom   = clamp(boredom   + 0.08 × T, 0, 1)                    // 无人互动会积累无聊
curiosity = clamp(curiosity − 0.03 × T, 0, 1)                    // 好奇随时间衰减
mood      = mood + (0.5 − mood) × min(T / 4, 1) × 0.6            // 向平静基线（0.5）回归
```

说明：

- 系数与封顶时长写在**角色包 JSON** 的 `offlineSettlement` 字段中，不硬编码；
- 情绪向 `0.5`（平静）回归而非归零，避免长时间关闭后角色显得消沉；
- 最后位置、最后活动、关注目标**保持暂停前的值**，不因离线改变；
- 离线**不结算**羁绊值、不写入记忆、不推进任何剧情事件；
- 离线时长不足 5 分钟时世界未暂停，不触发本结算。

## 5. 运行状态机（五态重定义）

保留桌宠时期的五态框架，触发条件按全屏游戏重定义：

| 状态 | 全屏游戏下的触发 | 穿透 | 表现 |
| --- | --- | --- | --- |
| Dormant | 失焦超过 5 分钟，或手动休眠 | — | 完全暂停渲染与生活结算 |
| Ambient | 默认空闲 | — | 角色按五活动持续生活 |
| Aware | 玩家有输入但未进入对话 | — | 角色注意到用户，可能看向屏幕 |
| Engaged | 对话 / 互动中 | — | 转向屏幕、3D 文字、口型、动作 |
| Focus | 番茄钟进行中 | — | 角色进入专注陪伴姿态，低干扰 |

状态机是渲染与生活调度的唯一事实源。插件只能请求语义动作，不能直接绕过状态机控制窗口。

## 6. 存档系统

**自动保存 + 单存档槽**，不提供多槽位，保持“持续世界”的单一真相。

保存内容三层：

- **角色档案**：人格、关系、羁绊、可迁移记忆；
- **世界存档**：当前活动、最后位置、关注目标、需求状态、环境状态；
- **当前组合**：正在使用的世界包 ID 与版本。

自动保存触发时机：

1. 退出程序时（含 Alt+F4）；
2. 关键事件后（对话结束、关系变化、重要互动）；
3. 每 5 分钟定时保存。

存档损坏时回退到上一个可用备份，并向用户明确提示，不静默丢弃。
