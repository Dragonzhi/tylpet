# tylpet 3D 异世界桌面 · 设计文档索引

> **状态**：活跃维护中（随讨论持续更新）
> **用途**：本目录是 3D 异世界桌面产品的全部设计决策记录。开发时按需加载对应文档，不要通读全部。

## 一页结论

玩家打开 tylpet 即进入一个异世界：Blender 风格的无限网格空间中，一个 VRM 角色按自己的生活节奏待机、漫步、休息，偶尔看向那块连接用户的半透明悬浮虚拟屏幕。玩家通过鼠标光点和点击与屏幕互动，通过游戏内聊天面板与她对话。

**第一阶段是独立全屏游戏**（无边框窗口化全屏，固定主显示器，启动直接进入世界），不是桌面叠加层。透明桌面叠加模式是第二阶段目标。

## 统一基线速查

| 主题 | 结论 |
| --- | --- |
| 产品形态 | **官方 IP 本体优先，社区为附加**：官方做透第一个角色与世界，社区包定位「给她换个家」；第一阶段只做可导入，不做工坊分享 |
| 窗口形态 | 第一阶段：独立全屏游戏（无边框窗口化全屏，固定主显示器）；第二阶段：透明桌面模式 |
| 空间 | 第一阶段 = Blender 无限网格（开发/验收场景，无人情味）；玩家首发场景 = 第二阶段官制「默认房间」（authored-scene） |
| 世界时间 | 与玩家本地时钟对齐，不持有独立时间；玩家上线永远看到「现在这个时刻的她」，不撞见她睡觉 |
| 休息 | 允许睡、可唤醒；入口=点击屏幕+发消息，均走 refusal 判定；拒绝有反馈、无冷却 |
| 天气 | 核心状态机，四态晴/阴/雨/雪；用独立乘子影响活动，不新增活动 ID；Phase 1 只做逻辑与单测，表现随默认房间落地 |
| 动作来源 | 预制 VRMA 为唯一来源；实时生成为远期愿景，只定义动作来源接缝、不实现生成器 |
| 自然感 | 程序化加性微动层为主引擎（呼吸/重心/眨眼/视线惯性，常驻叠加）；变体为辅助，Phase 1 每活动 1 片段 |
| 动作归属 | 片段与小动作习惯归角色包，世界包只提供锚点与适配条件；资产须同源且规范统一 |
| 人格注入 | 人格滑杆与需求/天气/活动**翻译成自然语言**注入 system prompt，不喂数字；映射表在角色包 |
| LLM 工具 | **第一阶段零运动工具**：模型不能指挥行为；允许受限的**内感受写入**（改需求/情绪，不改活动），带字段白名单、值域上限与频率限制 |
| LLM 与角色分层 | 人格=神经调质（只调增益）、需求=内分泌（慢变量、带时滞）、运行态=唤醒度、调度器=脊髓（只执行）；模型写感受不写行为 |
| 跨端（草案） | 世界是唯一事实源，游戏与文本端（QQ 等）只是观察孔；她在任何前端说的话必须能被世界状态解释，措辞自由、事实底唯一 |
| 无 key | 降级离线 Mock；首次启动引导填写并给出外发告知 |
| 上下文 | 三层：状态描述 + 记忆摘要（`memory.v1`）+ 最近 N 轮；完整聊天永不长期持久化 |
| 角色 | 授权清晰的现成开源 VRM；首个人格原型：安静观察者（内向/好奇/慢热） |
| 渲染 | Three.js + @pixiv/three-vrm + MToon 赛璐珞 + 三点布光；60fps 目标，画质三档 |
| 术语 | 悬浮虚拟屏幕 = 游戏内那块表示玩家屏幕的半透明悬浮界面，简称虚拟屏幕 |
| 世界关系 | 玩家画面 = 异世界悬浮虚拟屏幕的另一侧视野；角色知道屏幕后有人 |
| 交互 | 隐藏系统光标，羽化圆形光点为玩家唯一指针并映射到虚拟屏幕表面；点击 = 用户触碰信号；ESC 打开聊天与设置浮层（不暂停世界） |
| 状态 | Dormant（失焦暂停）/ Ambient（生活）/ Aware（有输入）/ Engaged（对话互动）/ Focus（番茄钟） |
| 角色活动 | 站立待机、网格漫步、休息发呆、观察屏幕、触碰屏幕等待回应；低频长时长 |
| 人格与自主 | 人格滑杆由角色作者配置，用户不可改写；角色可拒绝/延后请求；需求驱动（精力/好奇/无聊/情绪） |
| 文字 | 3D 悬浮打字 → 重力坠落 → 网格碰撞 → 粒子消散；按标点切分（≤24 字 / 同屏 3 段）；思源黑体子集化 MSDF |
| 音频 | lofi 背景音乐（免版权库 + 授权记录）+ 环境音 + TTS |
| 存档 | 自动保存 + 单槽；触发：退出、关键事件、每 5 分钟 |
| 创意工坊 | 完整世界包（角色+场景+物件+镜头+灯光+行为）；槽位化结构但第一阶段只整体切换；社区内容为官方 IP 的附加 |
| 门禁 | Phase 0 = 全屏 Three.js 性能基线 + VRM 动画质量门禁；不够好再评估更换引擎 |

## 第一版不做

1. 写实房间、墙面、书桌和窗户等大体量资产（**第一阶段**的网格不放物件；官制「默认房间」属第二阶段交付，见 [01-产品愿景](01-产品愿景.md) 第 8.1 节）；
2. WorkerW 桌面壁纸层注入；
3. 真 Bloom、复杂全屏后处理和高成本实时阴影；
4. 多房间、场景编辑器、手部 IK 和复杂路径行走；
5. 未完成授权审查的角色素材；
6. 创意工坊在线平台（第一阶段只做本地导入与管理）；
7. 多显示器完整适配，固定主显示器；
8. 槽位级资产替换（协议预留，第一阶段只整体切换世界包）；
9. 实时捕获用户桌面或操作真实桌面图标；
10. 世界核心抽取与文本前端接入（[11-跨端与外部接口](11-跨端与外部接口.md) 为草案，第一阶段仅锁定边界，不实现）。
