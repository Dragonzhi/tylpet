# 08 · 实施路线

> **状态**：定稿
> **上游**：全部设计文档
> **下游**：`计划.md`（动工后阶段进度在仓库级文档维护）

实施顺序为**先异世界核心，后游戏外壳**。开发期 3D 场景直接跑在 Tauri dev 窗口中。

## Phase 0：双 Spike（2~3 天，止损门）

- **Spike 1 性能基线**：Tauri dev 窗口 + Three.js 无限网格 + 现成 VRM + 三点光，验证 60fps 目标在 1080p/2K 中画质下可达，记录 GPU、内存和帧率曲线。
- **Spike 2 动画质量**：用现成 VRM + three-vrm 验证 MToon 质感、动作混合、LookAt 和 SpringBone 是否达到期望的“商业游戏级角色表现”。采用**逐项量化门禁**，四项全过才算通过，具体判据见 [07-渲染与性能 第 5 节](07-渲染与性能.md#5-动画质量验收phase-0-spike-2-门禁)。

**决策规则**：

| 结果 | 动作 |
| --- | --- |
| 双过 | 进入 Phase 1 |
| 性能不过 | 先优化资产与画质分级；仍不过 → 评估更换引擎 |
| 动画质量不过 | 记录具体差距（模型精度 / 动作库 / 着色参数），决定换模型、换动作资产还是换引擎 |

止损上限约 3 天。

## Phase 1：异世界核心（约 2~3 周）

在 Tauri dev 窗口中完成：无限网格、虚拟屏幕锚点与待机表现、VRM 加载与 MToon、三点布光、SpringBone、五活动调度器（待机/漫步/休息/观察屏幕/触碰等待）、光点指针与点击反馈、3D 文字分段与 MSDF 字体、需求与人格模型、首次固定脚本开场、**天气状态机逻辑（四态 + 转移矩阵，只接晴的表现）**。

对应设计：[02-角色系统](02-角色系统.md)、[03-屏幕与交互](03-屏幕与交互.md)、[07-渲染与性能](07-渲染与性能.md)、[06-世界包协议](06-世界包协议.md) 第 9 节。

**Phase 1 追加验收项**：天气状态机的 4×4 转移矩阵有单元测试覆盖（含非法转移、越界时长、恢复后状态延续），且单测通过——此项目逻辑先行、无视觉表现，属预期。

## Phase 2：游戏外壳（约 1~2 周）

无边框窗口化全屏、固定主屏、启动直达世界、ESC 聊天/设置浮层（不暂停）、退出三路径、托盘、自动保存与单槽存档、番茄钟 HUD 与 Focus 联动。**本阶段专门验证外壳类风险**（退出路径、焦点行为、托盘集成、存档恢复）。

对应设计：[04-游戏外壳](04-游戏外壳.md)。

## Phase 3：表现层（约 1~2 周）

3D 中文 SDF 文字管线（打字机、悬浮、坠落、碰撞、消散）、TTS 响度口型、音频三层（音乐/环境/TTS）与授权清单、画质三档设置。

对应设计：[05-表现层](05-表现层.md)、[07-渲染与性能](07-渲染与性能.md)。

## Phase 4：世界包协议与首个世界验收（约 1~2 周）

manifest 与目录结构、导入校验（结构 + 安全限制）、世界注册与切换、首个完整世界（安静观察者角色 + 网格 + 屏幕）打包与验收；输出可运行版本和演示视频。

对应设计：[06-世界包协议](06-世界包协议.md)。

整体按课余投入预计 2.5~3.5 个月，实际以 Phase 0 结果为准。每个 Phase 结束固定产出：可运行版本 + 实测数据 + 半页复盘。

## 风险表

| 风险 | 等级 | 应对 |
| --- | --- | --- |
| Three.js 动画质量不达预期 | 高 | Phase 0 Spike 2 前置验证；差距明确后换模型/换动作库/评估引擎 |
| 全屏 3D 性能不达标 | 高 | 画质三档兜底；资产面数与贴图收敛；仍不达标评估引擎 |
| VRM 动画资产工时膨胀 | 中 | 五活动封顶；现成 VRMA 优先，缺失时降级短距离移动 |
| 中文 3D 文字性能与字体版权 | 中 | SDF 方案；字体记录授权；并发上限与回收 |
| 外壳类问题暴露过晚 | 中 | Phase 2 专门安排退出、焦点、托盘、存档验证 |
| 音乐授权不清 | 中 | 只用免版权库并逐曲记录；随项目维护授权清单 |
| 世界包安全 | 中 | 结构校验 + 拒绝可执行/脚本 + 路径穿越检查 |
| 挤占主线时间 | 中 | 阶段门禁和三天止损线 |

## 最终验收清单

- [ ] 启动直达世界，首次进入有三段开场，之后恢复不重复播放；
- [ ] 角色五活动持续运行，活动结果（位置/关注/需求/记忆）可观察；
- [ ] 光点与点击屏幕有角色回应，回应层级符合 03 档规则；
- [ ] 角色休息时可被唤醒（点击屏幕 / 发消息双入口，拒绝判定可复现）；
- [ ] 聊天面板可用，打开时世界不暂停；
- [ ] 3D 文字浮现、坠落、弹跳、消散；
- [ ] TTS、记忆、番茄钟、托盘正常；
- [ ] 中画质 60fps 达标，画质三档可切换；
- [ ] 失焦低帧率与 5 分钟暂停正确；
- [ ] 自动保存与恢复正确，损坏时有备份回退；
- [ ] 世界包导入校验拦截非法内容（可执行文件、路径穿越、超大文件）；
- [ ] 业务域不反向依赖 Three.js；
- [ ] 监听、定时器、rAF 和资源均可释放，StrictMode / HMR 重挂载无泄漏。
